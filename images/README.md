# Screenshots Instructions

To add UI screenshots to the main README:

1. **Run the application**:
   ```bash
   python3 app.py
   ```

2. **Open browser** and go to `http://127.0.0.1:5002`

3. **Take screenshots**:
   - `ui-main.png` - Main interface (before uploading)
   - `ui-results.png` - Results page (after prediction)

4. **Save screenshots** in this `images/` folder

5. **Commit and push**:
   ```bash
   git add images/
   git commit -m "Add UI screenshots"
   git push origin main
   ```

## Recommended Screenshot Settings:
- **Resolution**: 1200x800 or higher
- **Format**: PNG for best quality
- **Browser**: Chrome/Safari for consistent rendering
- **Zoom**: 100% for accurate representation

## Screenshot Ideas:
- Main upload interface
- File selection dialog
- Processing/loading state
- Results with cat prediction
- Results with dog prediction
- Mobile responsive view
